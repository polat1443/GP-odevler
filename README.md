# GRAFİK PROGLAMLAMA Ödevleri Arşivi

Bu depo, Iğdır Üniversitesi Yazılım Mühendisliği Bölümü **Grafik Programlama** dersi kapsamında hazırladığım haftalık ödevleri, vize projelerini ve teknik raporları içermektedir.

## 📂 Proje İçeriği

| Ödev / Proje | Açıklama | Kullanılan Teknolojiler |
| :--- | :--- | :--- |
| **Ödev 1: Parametrik Çizici** | Rozet, Yıldız ve Kardioid gibi parametrik denklemlerin interaktif çizimi. | Python, Pygame |
| **Ödev 2: Titrasyon Simülasyonu** | Olay Yönelimli Mimari (EDA) ile asit-baz titrasyon sürecinin simülasyonu. | Python, Pygame, OOP |
| **Vize Ödevi: 2B Fizik Motoru** | Velocity Verlet ve Semi-Implicit Euler yöntemleri ile çarpışma tespiti yapan mini fizik motoru. | Python, Fiziksel Modelleme |
| **Ödev 4: 3B Sınıf Modelleme** | Gerçek sınıf fotoğrafı üzerinden 72 öğrenci kapasiteli 3D projeksiyon motoru. | Python, Matplotlib, NumPy |

## 🛠️ Kullanılan Teknolojiler ve Araçlar
* **Programlama Dili:** Python
* **Kütüphaneler:** Pygame, Matplotlib, NumPy
* **Ortam:** VS Code

## 🚀 Çalıştırma Talimatları
Projeleri kendi bilgisayarınızda çalıştırmak için:
1. Depoyu klonlayın: `git clone <depo-linki>`
2. Gerekli kütüphaneleri yükleyin: `pip install pygame matplotlib numpy`
3. İlgili ödev klasörüne girip ana Python dosyasını çalıştırın.
